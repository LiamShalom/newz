# Quick Task 260502-c55 — Truncate story to 2 lines + Read more

## Goal

The story paragraph below each SegmentCard (`segment.caption`, rendered at `frontend/src/components/SegmentCard.tsx:238-240`) currently shows the entire caption inline. It should default to 2 lines with an inline "Read more…" link; clicking expands to full and shows "Show less".

## Approach

CSS line-clamp + toggle. Avoid JS measurement of pixel heights — use the CSS-clamp + `scrollHeight`/`clientHeight` overflow detection pattern.

1. Add `expanded` state (default `false`).
2. Render the `<p>` with `line-clamp-2` when collapsed; remove the clamp when expanded.
3. Use a `useEffect` + ref to set `overflows` state by comparing `scrollHeight > clientHeight` after mount/resize/caption change. Hide the toggle when text fits in 2 lines.
4. The toggle is a small inline button styled as a subtle link in `text-ink-secondary` (or comparable), rendered on its own line below the paragraph. Click toggles `expanded`. The button does NOT propagate to the card's video controls — `e.stopPropagation()` defensively (card itself doesn't capture clicks here, but harmless).
5. Re-measure on `segment.caption` change so SSE caption updates re-evaluate overflow.

## Constraints

- No new dependencies.
- Tailwind 4 supports `line-clamp-2` natively (`@tailwindcss/line-clamp` is no longer needed).
- Match existing typography on the paragraph (text size, leading, color).
- Keep the existing `text-[13px] leading-[1.5] text-ink-primary` styling on the paragraph itself.
- Toggle text: "Read more" / "Show less" — no ellipsis character (CSS clamp already adds visual ellipsis).
