## NEW BAD Examples Added (failure mode flagged in both prompts)

Both prompts now explicitly call out the v1.0 caption pattern as the anti-pattern:

| Failure mode | Original (now BAD) caption opener | News-lede rewrite opener |
|---|---|---|
| Static tableau verb | "Roughly thirty people **stand** shoulder-to-shoulder..." | "Roughly thirty demonstrators **rallied** at..." / "Roughly thirty demonstrators **gathered** at..." |
| Static tableau noun | "**A row of** blue municipal bins **lies** overturned..." | "**Vandals overturned** a row of blue municipal bins..." |
| Descriptive participial syntax | "**A man in a dark hoodie walks** between two rooms..." | "**A resident paced** between two rooms..." / "**A resident moved** between two interior rooms..." |

These are the exact captions the v1.0 prompt was using as GOOD EXAMPLES — the model was copying them, hence the "video transcript, not news" complaint that triggered this task.
