### `backend/pipeline/compile.py` — new `_run_angle_selector_parallel` (service / agent-invocation)

**Analog:** `backend/pipeline/compile.py:_run_caption_writer_with_vision` (lines 205-249)

This is the **primary analog** for the new parallel angle-selector invocation. The existing caption-writer is already a standalone `query()` call (top-level, not orchestrator-nested) — exactly the shape needed for the new angle-selector parallel invocation.

**Standalone `query()` invocation pattern** (lines 221-242, 14 lines load-bearing):
```python
async def _prompt_stream():
    yield user_msg

options = ClaudeAgentOptions(
    system_prompt=CAPTION_WRITER_SYSTEM,
    model="sonnet",
    max_turns=1,
)

last_text = ""
async for msg in query(prompt=_prompt_stream(), options=options):
    if isinstance(msg, AssistantMessage):
        text = _extract_text_from_assistant(msg)
        if text:
            last_text = text
    elif isinstance(msg, ResultMessage):
        if msg.is_error:
            raise RuntimeError(
                f"caption-writer query error cluster_id={cluster_id} "
                f"errors={msg.errors}"
            )
        break
```

**Apply to new function** (suggested name: `_run_angle_selector(cluster_id) -> dict` returning `{"clip_ids": [...], "rationale": "..."}`):
- Replace `system_prompt=CAPTION_WRITER_SYSTEM` with the angle-selector prompt currently in `AGENTS["angle-selector"].prompt` (lines 85-99). Inline as a module-level constant `ANGLE_SELECTOR_SYSTEM`.
- Replace `max_turns=1` with `max_turns=10` (angle-selector needs to call `mcp__newz_tools__get_cluster_clips` then potentially N×`get_clip_metadata`).
- Add MCP wiring: `mcp_servers={"newz_tools": newz_tools_server}` and `allowed_tools=["mcp__newz_tools__get_cluster_clips", "mcp__newz_tools__get_clip_metadata"]`.
- Replace `prompt=_prompt_stream()` with `prompt=f"Cluster ID: {cluster_id}"` (a plain string — no vision needed; subagent fetches its own metadata via MCP).
- Keep the `last_text` accumulation + `ResultMessage.is_error` raise pattern verbatim.
- Reuse `_parse_caption_json` (lines 191-202) — it tolerates ```json fences and works for any JSON-output subagent. Rename in the docstring or generalize to `_parse_json_with_fences`.

### `backend/pipeline/compile.py` — new parallel orchestration (replaces `_run_orchestrator_chain`)

**Analog:** `backend/pipeline/compile.py:_run_agents` (lines 293-300) — currently sequential; the new version uses `asyncio.gather`.

**Existing sequential composition** (lines 293-300):
```python
async def _run_agents(cluster_id: str) -> str:
    """Run vision caption-writer, then the 3-subagent chain. Returns segment_id."""
    caption_data = await _run_caption_writer_with_vision(cluster_id)
    log.info(
        "compile caption written cluster_id=%s caption=%r location=%r",
        cluster_id, caption_data.get("caption"), caption_data.get("location"),
    )
    return await _run_orchestrator_chain(cluster_id, caption_data)
```

**Pattern to apply** (genuine Python-level parallelism via `asyncio.gather`):
```python
async def _run_agents(cluster_id: str) -> str:
    """Run caption-writer ‖ angle-selector in parallel, then publish via Python."""
    caption_data, angle_data = await asyncio.gather(
        _run_caption_writer_with_vision(cluster_id),
        _run_angle_selector(cluster_id),
    )
    log.info(
        "compile parallel done cluster_id=%s caption=%r location=%r clip_ids=%s",
        cluster_id, caption_data.get("caption"), caption_data.get("location"),
        angle_data.get("clip_ids"),
    )
    return await _publish_segment(
        cluster_id=cluster_id,
        ordered_clip_ids=angle_data["clip_ids"],
        caption=caption_data["caption"],
        location=caption_data["location"],
    )
```

**Notes for planner:**
- `asyncio.gather` will raise on first exception — caller (`compile_segment` line 338-349) already catches `Exception` and routes to `_save_fallback_segment`, so no special error handling needed inside `_run_agents`.
- The 60s `asyncio.wait_for` cap at line 338 stays untouched.
- Keep `_run_agents` as the named callable (existing tests in `test_compile_timeout.py` patch `backend.pipeline.compile._run_agents` — see lines 25, 58 of that file).

### `backend/pipeline/compile.py` — new `_publish_segment` (replaces publisher subagent)

**Analog 1 (in-file):** `backend/pipeline/compile.py:_save_fallback_segment` (lines 303-321) — the existing direct-Python `db.insert_segment` call. The new `_publish_segment` is structurally identical: take inputs, idempotency-check via `get_segment_for_cluster`, call `db.insert_segment`, return seg_id.

**Existing direct-Python insert pattern** (lines 303-321):
```python
async def _save_fallback_segment(cluster_id: str) -> str:
    """CMP-06: idempotent fallback. Chronological order, generic AP-wire caption."""
    existing = await db.get_segment_for_cluster(cluster_id)
    if existing:
        return existing["id"]
    clips = await db.fetch_cluster_clips(cluster_id)
    clip_ids = [c["id"] for c in clips]
    if clips:
        when = datetime.fromtimestamp(clips[0]["ts"], tz=timezone.utc).strftime("%b %-d, %Y")
    else:
        when = datetime.now(tz=timezone.utc).strftime("%b %-d, %Y")
    caption = f"Multi-angle event captured by {len(clip_ids)} contributors on {when}."
    return await db.insert_segment(
        cluster_id=cluster_id,
        ordered_clip_ids=clip_ids,
        caption=caption,
        location="Pasadena, CA",
        source_count=len(clip_ids),
    )
```

**Analog 2 (boundary):** `backend/db.py:insert_segment` (lines 250-276) — the canonical signature `_publish_segment` must call:
```python
async def insert_segment(
    cluster_id: str,
    ordered_clip_ids: list[str],
    caption: str,
    location: str,
    source_count: int,
) -> str:
    """Idempotent: one segment per cluster. ON CONFLICT(cluster_id) updates. CMP-09."""
```

**Pattern to apply** (new `_publish_segment` — call site for the parallel happy path):
```python
async def _publish_segment(
    cluster_id: str,
    ordered_clip_ids: list[str],
    caption: str,
    location: str,
) -> str:
    """Direct Python publisher — replaces the haiku publisher subagent (CMP-03).

    The haiku subagent silently skipped save_segment 67% of the time (spike 002).
    A direct db.insert_segment call eliminates that failure mode by construction.
    Idempotent via insert_segment's ON CONFLICT(cluster_id) clause (CMP-09).
    """
    seg_id = await db.insert_segment(
        cluster_id=cluster_id,
        ordered_clip_ids=ordered_clip_ids,
        caption=caption,
        location=location,
        source_count=len(ordered_clip_ids),
    )
    log.info(
        "publish_segment cluster_id=%s seg_id=%s clip_count=%d",
        cluster_id, seg_id, len(ordered_clip_ids),
    )
    return seg_id
```

**Notes for planner:**
- `_save_fallback_segment` is the unchanged timeout/exception path — `_publish_segment` is the happy-path twin. They both terminate in `db.insert_segment`. Do not collapse them — fallback has different inputs (chronological order, generic caption) than happy path (angle-selector order, vision caption).
- No `events.broadcast` call here — `compile_segment` (line 352) already broadcasts `segment_published` after `_run_agents` returns. Match that contract.
- Idempotency is provided by `insert_segment`'s `ON CONFLICT(cluster_id) DO UPDATE` (db.py:265) — no need for an explicit `get_segment_for_cluster` pre-check (that was a fallback-path concern for the case where the subagent partially succeeded).

## Shared Patterns

### Logging
**Source:** `backend/pipeline/compile.py:41` (`log = logging.getLogger(__name__)`)
**Apply to:** All new functions (`_run_angle_selector`, `_publish_segment`)
**Style** (line 280-282 example):
```python
log.info(
    "compile orchestrator done cluster_id=%s turns=%s duration_ms=%s",
    cluster_id, msg.num_turns, msg.duration_ms,
)
```
- printf-style `%s` (NOT f-strings) — lazy formatting, integrates with structured logging.
- Always include `cluster_id=%s` as the first key — every existing log line in this module does.

### Error handling — `ResultMessage.is_error` check
**Source:** `backend/pipeline/compile.py:236-241`
**Apply to:** New `_run_angle_selector` `query()` loop
```python
elif isinstance(msg, ResultMessage):
    if msg.is_error:
        raise RuntimeError(
            f"caption-writer query error cluster_id={cluster_id} "
            f"errors={msg.errors}"
        )
    break
```
Raise `RuntimeError` with `cluster_id` + `errors` context. Top-level `compile_segment` (lines 347-349) catches all `Exception` and routes to `_save_fallback_segment`. No need to redundantly catch internally.

### JSON parsing with code-fence tolerance
**Source:** `backend/pipeline/compile.py:_parse_caption_json` (lines 191-202)
**Apply to:** Angle-selector output parsing (the LLM may wrap JSON in ```json fences).
- Reuse the existing function as-is. Optionally rename to `_parse_json_with_fences` since it's now used for two different agents' outputs. Either rename or just reuse the misnamed function — the planner has discretion.

### Idempotency via DB (CMP-09)
**Source:** `backend/db.py:insert_segment` (lines 250-276) — `ON CONFLICT(cluster_id) DO UPDATE`
**Apply to:** New `_publish_segment`. Do NOT add a Python-level `get_segment_for_cluster` pre-check — the DB-level constraint is the single source of truth. Re-runs of `compile_segment` for the same cluster will harmlessly UPDATE the existing row.

### `compile_segment` outer envelope (UNCHANGED)
**Source:** `backend/pipeline/compile.py:compile_segment` (lines 324-356)
**Apply:** verbatim. The 60s `asyncio.wait_for` cap, the `compile_started`/`segment_published` broadcasts, the `finally: set_compile_in_flight(cluster_id, False)`, and the timeout/exception → `_save_fallback_segment` routing all stay. Only the body of `_run_agents` (the function this calls) changes.
