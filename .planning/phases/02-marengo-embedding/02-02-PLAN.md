STEP 2 — Add the _pre_warm_marengo function to app.py.

Add this function near the top of app.py (after imports, before or after existing lifespan):

```python
async def _pre_warm_marengo() -> None:
    """
    Fire-and-forget Marengo pre-warm.
    Pays the Twelve Labs cold-start cost before the first judge submits a clip.
    Failure is non-fatal — logs a warning and continues.
    Skipped entirely when USE_MOCK_EMBEDDINGS=true.
    """
    import config as _config
    if _config.USE_MOCK_EMBEDDINGS:
        log.info("pre-warm skipped (USE_MOCK_EMBEDDINGS=true)")
        return

    pre_warm_path = _config.PRE_WARM_CLIP_PATH
    if not pre_warm_path or not Path(pre_warm_path).exists():
        log.warning(
            "pre-warm skipped: PRE_WARM_CLIP_PATH=%r not found. "
            "Set PRE_WARM_CLIP_PATH to a valid clip file.",
            pre_warm_path,
        )
        return

    try:
        from pipeline.embed import _sync_embed
        loop = asyncio.get_event_loop()
        _, latency_ms = await loop.run_in_executor(None, _sync_embed, pre_warm_path, "__prewarm__")
        log.info("Marengo pre-warm complete latency_ms=%d", latency_ms)
    except Exception as exc:
        log.warning("Marengo pre-warm failed (non-fatal): %s", exc)
```

STEP 3 — Wire pre-warm into the FastAPI lifespan.

If app.py already has a lifespan context manager (from Phase 1), ADD `asyncio.create_task(_pre_warm_marengo())` inside the startup block. Do NOT remove existing lifespan code (DB init, cluster rebuild, etc.).

If no lifespan exists yet, create one:
```python
from contextlib import asynccontextmanager

@asynccontextmanager
async def lifespan(app: FastAPI):
    # --- startup ---
    asyncio.create_task(_pre_warm_marengo())  # fire-and-forget; does not block startup
    yield
    # --- shutdown (add cleanup here if needed) ---

app = FastAPI(lifespan=lifespan)
```

CRITICAL: Pre-warm must use `asyncio.create_task(...)`, NOT `await _pre_warm_marengo()`. Using await would delay the server from accepting requests until Marengo responds (20-30s). Use create_task so the server starts accepting requests immediately.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| startup → Twelve Labs API | Pre-warm sends a real clip to TL; API key in env, not code |
| env vars → config.py | PRE_WARM_CLIP_PATH could be set to an arbitrary path via env injection |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Information Disclosure | PRE_WARM_CLIP_PATH | mitigate | Path comes from env var, not user input; _pre_warm_marengo validates Path(pre_warm_path).exists() before opening — no arbitrary file read |
| T-02-07 | Denial of Service | Pre-warm blocking startup | mitigate | asyncio.create_task (not await) in lifespan; startup never waits on pre-warm; failure is logged as warning, not exception |
| T-02-08 | Information Disclosure | Pre-warm failure log | mitigate | Log the exception message only (str(exc)), not the full traceback which might include API key in auth headers |
| T-02-09 | Tampering | run_pipeline called with invalid clip_id | accept | clip_id comes from POST /clips which validates the DB insert; embed_worker already checks get_clip returns non-None |
</threat_model>
