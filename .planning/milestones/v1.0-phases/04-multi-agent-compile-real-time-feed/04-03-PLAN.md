## Feature 1 — Stitch encoder swap (RUNTIME-CMP-02, CMP-06)

**Why:** `stitch.py:45` uses `vcodec="libvpx-vp9"` which forces a full software VP9 re-encode of the concatenated 45s of 720p video. libvpx-vp9 runs at ~3-5 fps for 720p → 66s wall-clock. Compounding: source clips have mismatched specs (720×1296@30, 476×848@24, 720×1280@25 with B-frames), so naive `-c copy` stream-copy is not safe — clips need normalization. Validated fix: H.264 ultrafast + filter_complex normalize-then-concat → 0.52s wall-clock on the same input.

### Task 1.1 — Rewrite `_sync_stitch` to use H.264 ultrafast + normalize-and-concat

<task id="1.1" type="execute" autonomous="true">
  <action>

Drop the concat-demuxer + temporary file list; use one `ffmpeg.input` per clip with `ss`/`to` for trimming, run a `scale → pad → setsar=1 → fps=30` filter chain per input, then `concat=n=N:v=1:a=0`, encode with `libx264 -preset ultrafast -crf 28 -pix_fmt yuv420p -movflags +faststart`. Concrete replacement (target shape):

```python
def _sync_stitch(clip_refs: list[dict], output_path: str) -> str:
    if not clip_refs:
        return ""

    W, H, FPS = 720, 1280, 30

    inputs = []
    for ref in clip_refs:
        kwargs = {"ss": ref.get("start_offset_sec", 0.0)}
        if ref.get("end_offset_sec") is not None:
            kwargs["to"] = ref["end_offset_sec"]
        inputs.append(ffmpeg.input(ref["path"], **kwargs))

    norm = [
        inp.video
           .filter("scale", W, H, force_original_aspect_ratio="decrease")
           .filter("pad", W, H, "(ow-iw)/2", "(oh-ih)/2")
           .filter("setsar", 1)
           .filter("fps", FPS)
        for inp in inputs
    ]

    (
        ffmpeg
        .concat(*norm, n=len(norm), v=1, a=0)
        .output(
            output_path,
            vcodec="libx264",
            preset="ultrafast",
            crf=28,
            pix_fmt="yuv420p",
            movflags="+faststart",
        )
        .run(overwrite_output=True, quiet=True)
    )
    log.info("stitch ok output=%s", output_path)
    return output_path
```

- **Compile timeout from 60s:** Note compile.py:391 still uses `timeout=60.0` not 30.0. CLAUDE.md hard cap is 30s. After stitch fix, the headroom exists; consider tightening to 30s in a follow-up.
